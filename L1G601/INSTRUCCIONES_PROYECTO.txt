# INSTRUCCIONES PARA INICIAR Y PROBAR EL PROYECTO

## 1. Configuración de la base de datos MariaDB

1.1. Inicia el servicio de MariaDB:
   sudo systemctl start mariadb

1.2. Ingresa a MariaDB como root:
   sudo mariadb

1.3. Crea la base de datos y el usuario:
   CREATE DATABASE Grupo_c;
   CREATE USER 'UserRoot'@'localhost' IDENTIFIED BY '990928abc*';
   GRANT ALL PRIVILEGES ON Grupo_c.* TO 'UserRoot'@'localhost';
   FLUSH PRIVILEGES;
   EXIT;

1.4. Crea la tabla de usuarios:
   USE Grupo_c;
   CREATE TABLE usuarios (
       id INT AUTO_INCREMENT PRIMARY KEY,
       nombre VARCHAR(100) NOT NULL,
       correo VARCHAR(100) NOT NULL UNIQUE,
       contraseña CHAR(64) NOT NULL
   );

## 2. Configuración del backend (FastAPI)

2.1. Crea el archivo backend/.env con el siguiente contenido:
   DB_HOST=localhost
   DB_USER=UserRoot
   DB_PASSWORD=990928abc*
   DB_NAME=Grupo_c

2.2. Instala las dependencias necesarias:
   pip install --break-system-packages -r backend/requirements.txt

2.3. Inicia el backend:
   cd backend/mi_fastapi_env
   uvicorn app.main:app --reload

2.4. Verifica que el backend esté corriendo accediendo a:
   http://127.0.0.1:8000/docs

## 3. Configuración del frontend

3.1. Abre el archivo frontend/formulario3.html en tu navegador web.

3.2. Llena el formulario de registro con los datos requeridos y completa el captcha.

## 4. Verificar registros en la base de datos

4.1. Ingresa a MariaDB:
   sudo mariadb -u UserRoot -p

4.2. Selecciona la base de datos y consulta los usuarios:
   USE Grupo_c;
   SELECT * FROM usuarios;

## 5. Requisitos de seguridad de la contraseña

- Mínimo 8 caracteres
- Al menos una letra mayúscula (A-Z)
- Al menos una letra minúscula (a-z)
- Al menos un número (0-9)
- Al menos un símbolo especial (!@#$%^&*(),.?":{}|<>)

## 6. Notas y buenas prácticas

- Las credenciales de la base de datos deben ir siempre en el archivo .env y nunca en el código fuente.
- La contraseña se almacena de forma segura usando hash SHA-256.
- El backend valida que el correo no esté registrado antes de crear un usuario.
- El captcha protege el endpoint de registro contra bots.
- Si cambias la estructura de la base de datos, actualiza el modelo y las validaciones en el backend.
- Si tienes problemas de conexión, revisa que MariaDB esté corriendo y que los datos del .env sean correctos.

## 7. Otros comandos útiles

- Para reiniciar el backend tras cambios:
   CTRL+C para detener y luego ejecuta de nuevo:
   uvicorn app.main:app --reload

- Para instalar dependencias adicionales:
   pip install <paquete> --break-system-packages

- Para ver los logs de errores del backend, revisa la terminal donde ejecutas uvicorn.
